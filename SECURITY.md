# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately.

- Preferred: open a private GitHub Security Advisory for this repository.
- If that is unavailable, open a regular issue only for non-sensitive discussion and avoid publishing exploit details.

Include:
- A clear description of the issue
- Reproduction steps
- Impact assessment
- Suggested fix (if known)

We will investigate and coordinate a fix and release as quickly as possible.
